## 🚀 My Projects

### 🤖 [Rasa Chatbot](https://github.com/indrajanambiar/rasa_chatbot)
A comprehensive conversational AI assistant built with the Rasa framework. This project showcases:
- **Rasa NLU** for intent classification and entity extraction
- **Rasa Core** for dialogue management and conversation flow
- Custom actions and form handling for user interactions
- Support for multiple payment methods (Card, Cheque, UPI)
- Receipt generation and management workflows
- **Tech Stack**: Python, Rasa, spaCy, YAML configuration

**Key Features:**
- Multi-intent understanding (25+ different intents)
- Complex dialogue flows with form validation
- Custom action handlers for dynamic responses
- Integration with business logic (payments, receipts, accounts)
- Web UI integration with Rasa Chat widget
